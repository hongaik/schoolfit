⚡ Layer 2 — Pipeline Orchestration
graph.py — LangGraph StateGraph 8 nodes · conditional edges · retry loop · error routing Retry: filter_schools loops with radius × 1.5 (max 2 retries, cap 12 km) Compiled once at import; reused across all Streamlit runs
state.py — SchoolFitState TypedDict: single source of truth UserIntent (Pydantic) · 19 intent fields Auto-bump: w_sap/session/ip/mt/autonomous → 3 if LLM extracts preference RuleTrace list · filter_exclusion_log dict
↓ delegates to
🧠 Layer 3 — Intelligence & Reasoning
input_validator.py Form validation · geocoding (OneMap) build_user_intent() orchestrates all input processing parse_bonus_preferences(): LLM (gpt-4o-mini) → structured extraction via with_structured_output() → session, sap, ip, autonomous, mt, family context
nodes/summarizer.py LangChain LCEL ChatPromptTemplate | ChatOpenAI | StrOutputParser 3–5 bullet narrative grounded on score breakdown References raw values, not weights or norm scores
knowledge_base/ — Rule Engine 30 rules total · decorator registry · RuleTrace output R-F01–F03: filter (gender, distance, same-gender) R-T01–T03: travel mode selection R-S01–S13: score dimensions (11 dims + weight norm + final score) R-P01–P06: MOE P1 phase eligibility R-A01–A05: admission signal (Guaranteed/Likely/Competitive/Difficult) engine.run_all() · run_first_match() · describe()
input_helpers.py sentence-transformers (offline, no API cost) all-MiniLM-L6-v2 cosine similarity find_similar_cca() · find_similar_prog() Used at form input time (sidebar reactive search) Node 3 (derive_matches) reads selections — no semantic computation in graph
↓ API calls
🌐 Layer 4 — External APIs
OpenAI API gpt-4o-mini · temperature=0 input_validator: with_structured_output (bonus text) Node 8: StrOutputParser (summary) Key: st.secrets["OPENAI_API_KEY"]
OneMap — Geocoding /elastic/search?searchVal={postal} Node 1 (via input_validator) + Node 2 Returns X, Y, lat, lon · error edge on failure
OneMap — Routing /routingsvc/route (routeType=pt + walk) Node 5 · ThreadPoolExecutor (8 workers) Cached in _travel_cache{} · only successful results R-T rules select best mode · 10s timeout
api_clients.py @st.cache_resource (once per session) get_llm(model="gpt-4o-mini") → ChatOpenAI get_onemap_token() → bearer JWT Accepts raw password or pre-baked "eyJ…" JWT
